# 我的待办清单

一个不需要安装、双击就能用的待办清单。数据只保存在你自己的浏览器里，不上传任何服务器。

## 怎么用

直接双击 `index.html`，用浏览器打开即可。

- 输入内容后按 **回车** 添加
- 点圆圈或文字可以 **勾选完成 / 取消完成**
- 鼠标移到某一条上，右侧出现 **×** 可以删除
- 顶部 **全部 / 未完成 / 已完成** 切换筛选
- 底部 **清除已完成** 一次性删掉所有已完成项

## 目录结构

```
.
├── index.html         页面骨架
├── css/
│   └── style.css      样式
├── js/
│   └── app.js         全部逻辑
└── README.md          你正在看的这个文件
```

## 技术说明

纯原生 HTML + CSS + JavaScript，没有构建步骤、没有依赖、不用装任何东西。
待办数据存在浏览器的 `localStorage` 里（键名 `todo.tasks.v1`），换浏览器或清除站点数据会丢失。
